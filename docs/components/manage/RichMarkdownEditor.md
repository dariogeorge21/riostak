# `components/manage/RichMarkdownEditor.tsx`

WYSIWYG and raw markdown authoring editor for the `/manage` curator console.

## Features
- Toggleable split view / raw markdown / formatted visual editing.
- Instant toolbar controls for bold, italic, headings (H1-H3), bullet lists, numbered lists, blockquotes, code fences, and links.
- Bidirectional synchronization with hidden form fields for Server Action mutations.
- Preserves clean semantic markdown source without vendor HTML contamination.
