# `components/blogs/MarkdownRenderer.tsx`

Rich markdown rendering component for monographs and field notes in the reader drawer.

## Features
- Sanitized HTML rendering derived from markdown source strings.
- Academic typography styles using Tailwind typography (`prose` / Swiss editorial tokens).
- Code block highlights, blockquotes, heading hierarchies, ordered and unordered lists, bold/italic annotations, and external link formatting with security attributes.
