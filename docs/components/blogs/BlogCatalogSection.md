# BlogCatalogSection Component (`components/blogs/BlogCatalogSection.tsx`)

## Overview

Interactive presentation component for RIOSTAK published monographs and despatches.

## Key Features

- **Series Filter Pills:** Dynamic category tabs with ARIA tab roles (`Editorial Dispatches`, `Fellowship Essays`, `Monograph Series`, `Working Papers`).
- **Inline Monograph Reader:** Clicking "Read Full Monograph" reveals the complete formatted treatise directly within the catalog list without full-page navigation.
- **Accessibility:** Keyboard operable (`Escape` key closes the reader drawer), visible focus rings, WCAG 2.2 AA compliant contrast.
