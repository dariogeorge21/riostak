# `components/landingPage/Hero.tsx`

Server Component. Editorial landing hero with a dark primary surface, oversized typographic statement, and a single focused course CTA. The portrait is presented as an offset, framed image object with a restrained archive label rather than a conventional card. The bottom baseline provides the scroll prompt and a short supporting quote. Uses `next/image` with `priority` for the above-the-fold portrait and keeps the page's existing `/courses` and `/#about` navigation routes.
