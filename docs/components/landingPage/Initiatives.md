# `components/landingPage/Initiatives.tsx`
Core Initiatives: three alternating editorial `<article>`s driven by the `Offering` config (`#learn`, `#research`, `#library`) inside the `max-w-screen-2xl` container. Features a scaled-up responsive typographic hierarchy for laptop and desktop screens (`lg:` and `xl:`), enhancing the index numbers (`lg:text-headline-sm`), offering titles (`lg:text-[2.5rem] xl:text-headline-lg`), tags (`lg:text-label-md xl:text-label-lg`), body narrative (`lg:text-body-lg xl:text-[1.2rem]`), and CTA buttons (`lg:text-label-md` with `lg:h-10 lg:w-10` icons). Per-offering fields control image side, offset color block, caption position, and image treatment.
