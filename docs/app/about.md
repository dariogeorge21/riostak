# `app/about/page.tsx`

About page entrypoint (Server Component).

Displays a minimalist, high-typography "About Page — Coming Soon" announcement for RIOSTAK:
- Status breadcrumb with live-pulsing amber indicator (`Dossier 01 // Under Active Curation`).
- Monumental headline, Newsreader serif thesis statement, and explanatory institutional copy.
- Primary CTA to return home (`/`) and secondary CTA to explore curricula (`/#learn`).
- Three architectural preview cards detailing upcoming charter sections (`Charter & Trust`, `Faculty & Fellows`, `Methodology`).
- Edge-to-edge baseline ticker with institutional metadata stamps.
- Wrapped by the global `Header` and `Footer` in `app/layout.tsx`.
