# `app/portfolio/page.tsx`

Portfolio page entrypoint (Server Component).

Displays a minimalist, high-typography "Portfolio Page — Coming Soon" announcement for RIOSTAK:
- Status breadcrumb with live-pulsing amber indicator (`Archive // Series 04 Indexing In Progress`).
- Monumental headline, Newsreader serif pull-quote, and narrative explaining the ongoing index of 150+ papers and monographs.
- Primary CTA to return home (`/`) and secondary CTA to explore working papers (`/#research`).
- Three architectural preview cards detailing upcoming folio collections (`Longitudinal Indices`, `Post-Industrial Curricula`, `Diagnostic Manuals`).
- Edge-to-edge baseline ticker with jurisdiction metadata stamps.
- Full layout shell including `Header` and `Footer`.
