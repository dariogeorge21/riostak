# `app/blogs/page.tsx`

Blogs & Despatches page entrypoint (Server Component).

Displays a stylish, minimalist, high-typography "Blogs & Despatches — Coming Soon" announcement for RIOSTAK:
- **Status Breadcrumb**: Live-pulsing amber beacon (`Despatches // Volume 01 In Editorial Peer Review`) with inaugural release timeline.
- **Monumental Headline & Editorial Copy**: Space Grotesk display typography with an italic Newsreader serif thesis statement and institutional summary.
- **Interactive CTAs**: Return home (`/`) and explore research inquiries (`/#research`).
- **Architectural Preview Cards**: 3 preview blocks covering upcoming publication series:
  - `01.01 // Editorial Dispatches`: Neurobiology & Contemplation
  - `01.02 // Fellowship Essays`: Global Laboratory Field Notes
  - `01.03 // Monograph Series`: Post-Industrial Pedagogy
- **Edge-to-Edge Baseline Ticker**: Full-width baseline bar with editorial peer review status and global desk stamps.
- **Layout Shell**: Full layout including global `Header` and `Footer`.
